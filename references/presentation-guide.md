# O奖论文呈现指南

## 推荐页面逻辑

Summary Sheet → 问题重述与目标 → 假设/符号/数据 → 子问题模型 → 结果与验证 → 敏感性/限制 → 结论与建议 → 参考文献/附录。

摘要要独立可读：用少量句子交代方法、最重要的数值或排序、推荐方案、稳健性和限制。不要把摘要写成题目复述或引言复制。

## 图表规则

| 目的 | 优先图形 | 必须说明 |
|---|---|---|
| 趋势 | 折线/面积图 | 时间、单位、分组、关键转折 |
| 比较 | 排序条形图/点图 | 基准、误差或置信区间 |
| 关系 | 散点/热图/网络图 | 变量含义、尺度、边界 |
| 机制 | 流程图/状态图 | 节点、方向、状态转移 |
| 不确定性 | 箱线图/带状图/情景带 | 样本、重复次数、参数范围 |
| 优化 | 可行域/帕累托前沿/方案表 | 约束、目标、取舍 |

每张图都要有编号、短图注、单位和来源；正文必须解释读者应从图中看到什么。图片只能承担机制解释、空间关系或结果证据，不能作为装饰。

## 版式与可读性

- 默认采用单栏或局部双栏；双栏应服务于信息密度，不能牺牲图表可读性。
- 统一标题层级、公式编号、图表编号、颜色语义和页眉页码。
- 颜色优先使用少量高对比色，并提供灰度/色盲可读性；不要让颜色成为唯一编码。
- 每页保留足够留白；避免把长公式、宽表格和图注压缩到不可读。
- 以当年官方规则为准核对字号、页数、Summary Sheet、匿名、PDF、引用和附录计数；不要把旧年份规则套到新年份。

## 最小图表集

通常只保留：1 张问题/系统示意图、1 张核心结果图、1 张敏感性或误差图、1 张方案比较表。若题目本身需要更多图，增加前先说明其决策功能。
