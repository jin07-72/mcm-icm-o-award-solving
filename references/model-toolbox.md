# 模型工具箱

| 题面信号 | 候选模型 | 关键验证 |
|---|---|---|
| 连续时间、物理过程 | 微分方程、守恒/能量模型 | 参数敏感性、边界情景、量纲检查 |
| 预测、分类、评分 | 回归、树模型、时间序列、贝叶斯模型 | 留出/交叉验证、基线、误差分层 |
| 资源分配、路径、排班 | 线性/整数规划、网络流、启发式 | 可行性、上下界、替代权重 |
| 多标准排序 | 标准化加权、AHP/熵权、TOPSIS、Pareto | 权重敏感性、排序稳定性 |
| 人群/疾病/信息扩散 | Markov、SEIR、网络传播、主体仿真 | 初值/参数扰动、现实数量级、情景比较 |
| 排队、疏散、交通 | 排队论、离散事件仿真、最短路 | 到达率/服务率扰动、拥堵极端情景 |
| 策略互动 | 博弈、机制设计、演化仿真 | 均衡合理性、策略扰动、反事实 |
| 政策与社会系统 | 指标体系、因果/面板、系统动力学 | 替代指标、结构假设、政策副作用 |

## 选择纪律

先给可解释基线，再给复杂模型；复杂度增加必须带来可量化收益或更好的机制解释。任何黑箱模型都要补充特征定义、数据切分、误差分析和可解释性。
